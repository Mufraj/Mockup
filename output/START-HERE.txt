AMAZON SETUP
Upload the separate image modules through Amazon Store Builder.
The manifest supplies order, dimensions, copy, alt text and source provenance.
Assign confirmed Amazon ASINs or Store-page destinations in Builder;
destination fields are currently unassigned. CTA labels are part of the artwork.
Amazon supplies navigation and shopping behavior.
Specification reference: https://advertising.amazon.com/resources/ad-specs/stores/

EDIT AND REBUILD (from project root)

2. python output/generate-benchmark-artwork.py
3. node output/export-amazon-modules.cjs
4. python output/pack-amazon-assets.py
